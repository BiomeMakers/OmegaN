# Documents

`rewiring_attribution.md` — a gap-matched construction for the performance
attribution problem in graph rewiring, and a preliminary run on three matched
pairs. Preliminary: the limitations are stated in the document and are as
important as the result.

Scripts that reproduce it are in `../experiments/rewiring_pairs.py` (builds the
matched pairs) and `../experiments/rewiring_train.py` (trains and compares).
